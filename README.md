Shared Server

Shared Server is the backend that other apps call for AI replies.

It holds one Claude key so no other app needs its own. Its page shows a status check. It also serves the roast, push, and fleet apps for HeckleTroll, and the reskin grader for Repo Cloner.

Latest change. 2026-11-17, v2026.11.17. Added the repo-cloner-score app for Repo Cloner, which grades open source games as reskin bases.
